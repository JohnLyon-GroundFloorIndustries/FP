Privacy & your choices.

No inquiry collection here

This static preview has no inquiry form, database, staff login, client portal, marketing signup, or analytics scripts. It does not save event details or send messages. The menu uses a small script that stores no personal information.

Hosting

When this site is hosted on GitHub Pages, GitHub processes technical information, including visitor IP addresses, for security. See GitHub’s Pages documentation and GitHub’s privacy statement.

External links

The studio’s existing contact page and linked social platforms operate separately. Their privacy practices apply when you visit them. No inquiry details are forwarded by this preview.

Public preview

GitHub Pages is publicly accessible under ordinary Pages publishing. Search-engine exclusion is requested, but it is not password protection. Business copy and image permissions must be approved before using this preview as the public business website.
