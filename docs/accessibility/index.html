ACCESSIBILITY

An open invitation.

Using this website

The site is designed toward WCAG 2.2 AA, with keyboard navigation, visible focus, readable contrast, and reduced-motion support. This is a design target, not a claim of independently certified conformance.

If something gets in the way

If you encounter a barrier, contact the studio through its existing contact page. This static preview has no online submission form.

Ongoing review

New content and third-party services require continuing review. Automated checks are supplemented by keyboard and responsive-layout checks; a full assistive-technology audit remains part of launch acceptance.
